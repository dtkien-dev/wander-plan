# WanderPlan 0.12.0 — toasts with local history, Excel auto-fit

Status: released 18/10/2026 (Asia/Saigon). PR #10 merged as `cb2d549`. Customer decisions A037; go-live approval A038.

## Scope

- Action results (saved, deleted, Excel import/export, invitation and member actions, errors) show as toasts at the top right (full width on phones) instead of inline boxes with a "Đóng" button. Success toasts hide after 3 seconds and pause while hovered or focused; errors stay until closed. Dialog form errors stay inside the dialog.
- The newest 50 messages are kept per account in this browser (localStorage) and listed behind a bell in the top bar with time, delete one and delete all. Nothing is sent to the server; history is not synced to other devices and disappears if browser data is cleared.
- Excel report sheets size each column from its longest text (10–50 characters) and wrap long columns (address, notes, participants, split detail) at 40 with an estimated row height and top alignment. The import template keeps fixed widths.
- On screens up to 370px the top bar shows only the logo so the bell fits.

## Security review (same agent)

History stores only messages the user already saw, in their own browser, keyed by account id; another account on the same browser sees a separate list. Stored data is validated on read and storage failures fall back to memory. Messages render as React text. No new network calls, dependencies, permissions or database changes.
