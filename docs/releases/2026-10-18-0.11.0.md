# WanderPlan 0.11.0 — multi-day itinerary activities (R11 part 2)

Status: local candidate on `feat/multi-day-itinerary`; not deployed. Customer rules: A033.

## Scope

- Itinerary activities get an optional "Đến ngày". Start time belongs to the first day and end time to the last day, so an activity may run 20:00 on 27/11 → 08:00 on 29/11. Without an end date the existing same-day rule (end after start) still applies.
- The list shows a multi-day activity under every day of its range as "Ngày k/n": the start time on the first day, "Cả ngày" in between, "Đến <end time>" on the last day. Edit and delete act on the single activity.
- Overlap warnings compare continuous [start, end) intervals across days; touching endpoints do not warn and saving is never blocked. A multi-day clash names its dates.
- Excel LichTrinh gains a "Đến ngày" column (blank = one day). Files without the column still import, and updated rows keep their saved end date. Export writes the column.
- Estimated cost stays one amount per activity; the dashboard is unchanged.

## Database

Migration `20261018000000_multi_day_itinerary.sql`: nullable `itinerary_items.end_date`; the time check applies only without an end date; the end date must follow the start date and stay inside the trip; trip date changes account for it. `import_trip_data(uuid, jsonb, jsonb)` keeps its signature and grants, reads `end_date`, and keeps the stored value when a row omits the key (protects cached 0.10.0 clients).
