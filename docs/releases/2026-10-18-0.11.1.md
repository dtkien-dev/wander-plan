# WanderPlan 0.11.1 — readable Excel export

Status: released 18/10/2026 (Asia/Saigon). PR #8 merged as `40ea587`; go-live approval A036. Customer request 18/10: check the exported Excel file is tidy and easy to read (decision A035).

## Findings and fixes

- Text colours were never applied: the code passed `color`, but write-excel-file 4.x reads `textColor` (renamed in its 4.0 changelog), so headers showed bold black text on the dark green fill, the title was not green and the notes were not grey. Fixed for the report and the import template; a test now fails if a `color` key returns.
- "Đến ngày" sat after "Ghi chú", far from "Ngày". It now follows "Ngày" directly in LichTrinh and ChiPhi (report and template). Import still matches columns by header name, so files exported by 0.11.0 or earlier still import.
- Data sheets now show gridlines (header row stays frozen), and address/notes cells wrap.
- Unchanged: dd/mm/yyyy dates, #,##0 right-aligned money, column widths, ID/Version for re-import, summary sheet. No database or data change.
