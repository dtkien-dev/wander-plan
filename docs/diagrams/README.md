# Diagram assets

- `membership-process.svg`: BPMN-style business process with responsibility lanes, events, tasks and exclusive gateways. Technical exception paths are intentionally omitted.
- `system-architecture.svg`: current service boundaries, synchronous calls and asynchronous change notifications. The SVG embeds its technology logos and makes no external image requests.

Both files are editable SVG source. Update them when the corresponding implementation changes. All authored labels are in English. UI labels quoted in the root README are English translations; the application UI remains Vietnamese.
