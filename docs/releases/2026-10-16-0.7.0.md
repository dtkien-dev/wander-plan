# WanderPlan0.7.0 — Unified website interface

The Group page now leads with a compact trip summary. Owners edit settings in a focused dialog; members and the checklist sit side by side on desktop and stack on smaller screens. Personal name settings and trip archiving use labelled disclosures, keeping everyday collaboration prominent. Capacity guidance opens and focuses the correct editor field.

The same release refines Dashboard, Itinerary, Expenses, Login, the trip toolbar, shared headings, forms, dialogs and empty states. Existing green identity, bundled fonts and foundation tokens are retained. Smaller headings, clearer number hierarchy and consistent spacing reduce visual clutter. Itinerary actions wrap on narrow screens; bottom navigation starts before the desktop header overflows on tablets. Mobile dialog actions fill the available width.
